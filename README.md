# 🍛 Anna-Setu: Campus Food Rescue & Bio-Recycling Network

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://anna-setu-project-koankcapp5g58vt67b9sibn.streamlit.app/)

**Anna-Setu** (*"Food Bridge"* in Hindi) is a campus surplus food rescue and plate-waste bio-recycling management platform. It bridges institutional dining halls with nearby community shelters, enforces national food safety standards (FSSAI Surplus Food Regulations 2019), and simulates the conversion of non-edible plate waste into dry soil conditioner via a PTC bio-recycler.

> **Canonical app file:** `streamlit_app.py` — this is the deployed Streamlit application.
> `app.py` is a **legacy Gradio prototype** kept for reference only. It will not run unless Gradio is manually installed (not in `requirements.txt`).

## 🌟 What the App Does

### 1. 🍛 Donate Surplus Food (Track A)
- **Rule-based safety engine + keyword retriever:** Evaluates food against FSSAI Surplus Food Regulations (2019) using deterministic holding-time and temperature rules, with TF-IDF keyword retrieval over a local clause database. **Not an LLM — answers come from the rule engine, not generated text.**
- **Shelter proximity routing:** Matches to illustrative sample shelter data (Rain Basera network, Lucknow) based on zone proximity, capacity, and cold-chain availability.
- **WhatsApp broadcast generator:** Compiles a copy-paste volunteer alert with gate pickup directions and food quantities.
- **Handover record (FSSAI Schedule II fields):** Generates a decision-support manifest; the mess manager remains accountable as the FBO.

### 2. 🔮 Plan How Much to Cook
- **Attendance multiplier model:** Estimates dining hall turnout using fixed multipliers for day of week, weather, and academic calendar events — not regression-trained.
- **Editable baseline buffer:** Compare against your kitchen's actual overproduction buffer (default 25%, user-adjustable).
- **Ingredient bill of materials:** Per-category kg procurement targets with totals row.

### 3. ♻️ Plate-Waste Recycler (Track B)
- **Student kiosk simulator:** Shows real-time water and carbon footprint for a tray return.
- **PTC bio-recycler model:** Estimates dry biomass output (15% dry-weight yield, pending NPK testing).
- **ESP32 payload simulator:** Shows the JSON a hardware kiosk would POST to the API server.

### 4. 💬 Ask a Food Safety Question
- **Keyword-matched clause retrieval:** TF-IDF search over FSSAI and LNN clause database. Answers are assembled from retrieved clauses — not generated by an LLM. Safety verdicts always come from the deterministic rule engine.

### 5. 📖 Food Safety Rules Reference
- Plain-language guide covering the 2-hour/4-hour rule, temperature danger zones, donor legal protections (Schedule II fields, not Form B), and municipal compliance notes.

## 🚀 Quickstart & Local Setup

```bash
# Clone the repository
git clone https://github.com/pgovila/Anna-Setu-Project.git
cd Anna-Setu-Project

# Install dependencies (Streamlit + scikit-learn + numpy — no Gradio required)
pip install -r requirements.txt

# Run the interactive Streamlit application
streamlit run streamlit_app.py
```

The app opens at `http://localhost:8501`. Tested on Python 3.10–3.12.

## ⚠️ Limitations & Honest Caveats

| Area | Limitation |
|---|---|
| **Safety engine** | Rule-based deterministic engine. Not an LLM or trained model. Category time limits are based on FSSAI Reg 4(2) published thresholds; exact values should be verified with a food safety officer before operational use. |
| **Shelter data** | Illustrative sample data only. Rain Basera shelter names, zones, and contacts are based on publicly listed LNN night shelters — not verified live feeds. Confirm current operational status before dispatching. |
| **LNN clauses** | FSSAI Reg 3, 4(1), 4(2), 4(3), 4(4) are drawn from the published 2019 regulation. LNN section numbers (Sec 10, 12, 18, 21) are cross-referenced from the LNN SWM By-Law framework; Sec 14 (transit protocol) is a **project-authored engineering summary** based on FSSAI ambient limits and local traffic conditions — exact section and penalty values should be verified against the published LNN gazette. |
| **Attendance model** | Fixed multipliers for day, weather, and calendar — not regression-trained. Accuracy depends on how well defaults match your campus. Use your own swipe-card log data to calibrate. |
| **Track B biomass** | 15% dry-weight yield from PTC dehydrator is a modelled estimate. NPK values and suitability as soil conditioner require curing and independent lab testing before use. |
| **IBM Granite** | Roadmap only. The live app does not call any IBM Granite or external LLM API. |

## 📊 Impact Assumptions — Reconciled

**Reference scenario:** 850-diner hall, 175 g plate waste/diner, 10% kiosk capture rate, 240 operating days/year. All figures are **modelled estimates**.

| Metric | Arithmetic | Value | Note |
|---|---|---|---|
| Plate waste/diner | 175 g default | 175 g/meal | Slider default |
| Dry biomass yield | 15% of wet weight | PTC estimate | Pending NPK testing |
| Track B captured/day | 850 x 0.175 kg x 10% | 14.9 kg/day wet | 10% kiosk capture |
| Track B dry biomass/day | 14.9 x 0.15 | 2.2 kg/day | |
| Track B dry biomass/year | 2.2 x 240 | ~535 kg/yr | Landing page tile |
| Track B 100% capture (app default) | 850 x 0.175 x 0.15 x 240 | 5,355 kg/yr | App at 850 diners |
| Track A meals rescued/yr | 12,000 meals modelled | — | 20% of daily surplus |
| Track A kg rescued/yr | 12,000 x 0.35 kg | 4.2 MT/yr | Landing page tile |
| GHG avoided (Track A) | 4,200 kg x ~1.9 | ~8 MT CO2e | Factor unverified exactly |
| GHG factor | ~1.9 kg CO2e/kg | Approx landfill estimate | Not confirmed IPCC AR5 Tier 1 |
| Water per meal (Plan tab) | 0.35 kg x 760 L/kg | 266 L/meal | Same factor as per-kg |
| Water per kg (Track B) | 760 L/kg | 760 L/kg | Mekonnen & Hoekstra 2011 |
| Water total (Track A) | 4,200 MT x 760 L/kg | ~3,200 KL/yr | Landing page tile |
| Kiosk CO2e factor | 2.3 kg CO2e/kg food | Lifecycle estimate | Different from landfill 1.9 |

> **Key corrections from previous version:** 480 kg was removed (3.2 MT x 0.15 implies ~76 diners, inconsistent). 850 KL water was wrong; corrected to ~3,200 KL. ~6 MT CO2e was wrong for 4.2 MT x 1.9; corrected to ~8 MT. 266 L/meal and 760 L/kg are the same factor (0.35 kg x 760 = 266).
